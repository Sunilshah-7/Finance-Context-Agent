# AMD Hackathon 2026 - AI Project Ideas

This repository contains innovative project ideas for the [AMD Developer Hackathon](https://lablab.ai/ai-hackathons/amd-developer), designed to showcase how AMD GPUs and the AMD Developer Cloud can power cutting-edge AI workloads at scale.

## 🎯 Hackathon Overview

**Event:** AMD Developer Hackathon 2026  
**Focus:** AI Agents, Agentic Workflows, Vision & Multimodal AI, and Custom Model Training  
**Platform:** AMD Developer Cloud + Hugging Face Integration

## You can find project ideas at [ideas.md](ideas.md).

## Detailed Project Plan

- [FinContext Agent](fincontext-agent/README.md): portfolio-aware financial intelligence platform using AMD GPUs, AMD Developer Cloud, Hugging Face models, and Cloudflare deployment.

## 🚀 Getting Started

### Prerequisites

- Access to [AMD Developer Cloud](https://developer.amd.com/)
- [Hugging Face](https://huggingface.co/) account
- Python 3.8+ and common ML libraries

### Recommended Stack

- **LLMs:** Qwen, Llama 2/3, Mistral, DeepSeek
- **Vision Models:** Qwen-VL, Llama Vision, CLIP
- **Frameworks:** LangChain, LlamaIndex, vLLM
- **Deployment:** Hugging Face Spaces, AMD Developer Cloud

---

## 🔧 Development Guidelines

1. **Start Small:** Prototype with smaller models first
2. **Leverage AMD GPU Advantages:** Focus on high-throughput, memory-intensive workloads
3. **Showcase Performance:** Benchmark and compare with standard deployments
4. **Public Demo:** Deploy on Hugging Face Spaces for visibility
5. **Documentation:** Clear architecture diagrams and setup instructions
