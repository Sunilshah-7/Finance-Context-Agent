# packages/schemas

Shared data contracts for Python services and TypeScript apps.

## Build Responsibilities

- Define canonical Pydantic models.
- Generate TypeScript types.
- Version API contracts.
- Keep frontend, Worker, and Agent API payloads aligned.

## Core Schemas

- User.
- Portfolio.
- Holding.
- Document.
- Chunk.
- Citation.
- DisclosureChange.
- RiskScore.
- AnalystMemo.
- AnalysisJob.
- Finding.
