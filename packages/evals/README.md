# packages/evals

Evaluation harness for retrieval, citations, risk scoring, and AMD GPU benchmarks.

## Evaluation Suites

- Retrieval recall.
- Citation precision.
- Disclosure diff quality.
- Risk score stability.
- Compliance guardrail checks.
- Latency and throughput.
- Cost proxy by GPU minutes.
